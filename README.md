# Distribution Management Portal

A web-based Distribution Management Portal developed with **Node.js, Express.js, MongoDB, and EJS**. The system allows managers and buyers to manage products, inventory, orders, and payments.

### Features
- Product and inventory management
- Buyer account management
- Order placement and approval
- Payment integration with NotchPay
- Role-based authentication and access control

### Technologies
Node.js | Express.js | MongoDB | Mongoose | EJS | CSS
